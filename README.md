## ⚡ Project Overview

This is an innovative, high-performance, and futuristic landing page crafted specifically for **Techfest, IIT Bombay**. Built completely **without any 3D models or heavy 3D assets** (strictly complying with project requirements), the experience achieves a cyber-aesthetic through:

- **Interactive 2D Constellation Canvas**: High-fps mouse-reactive particle constellation system with neon nodes and velocity repulsion.
- **Festival Arenas Dynamic Showcase**: Detailed interactive rulebook and statistics views for *International Robowars*, *Tech Expo*, *Competitions*, *Global Summit*, *Techfest World MUN*, and *Technoholix Nights*.
- **Interactive Searchable Competitions Matrix**: Live filtering for Robotics, AI & Green Mobility, Quant/Coding, and Metaverse challenges with prize pools and direct registration triggers.
- **Embedded Interactive Mainframe Terminal (`CLI`)**: Interactive bash terminal allowing visitors to query festival parameters directly via commands (`theme`, `robowars`, `prizes`, `stats`, `campus`, `help`).
- **Interactive Pass Generator & QR Issuance**: Generates instant digital delegate passes with live canvas confetti and unique cryptographic verification IDs.
- **Festival 3-Day Timeline**: Chronological event schedule covering inauguration, combat bouts, keynote talks, and drone spectacles.

## 🚀 Quick Start Guide

### 1. Prerequisites
- Node.js (v18+ or v20+)
- npm

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/dewanshlohakare1234/techfest-landing
cd techfest-landing

# Install dependencies
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Visit `http://localhost:5173` in your browser.

### 4. Build for Production
```bash
npm run build
npm run preview
```
